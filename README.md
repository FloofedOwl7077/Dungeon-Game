# Dungeon Game

This is a work in progress dungeon crawler, using the 5e ruleset. Currently, none of the rules have been implemented, but the foundations are being constructed. This is entirely constructed in Python.

## Running the Game
There is one way I am aware of to run the game at this point. I intend to create a file that one can double click in their file explorer to run, but I have not reached that point. 

After downloading the program, open it in Visual Studio code. You can run it in one of two ways:

### Direct (Simplest)
Click the Run Python File arrow in the top right corner of the center panel.

### Through the Terminal
1. Right-click the game folder and choose 'Open in Integrated Terminal.
2. Run the command 'python main.py' (ignoring quotation marks)

## Key Bindings

### Movement
1. Arrow Keys (Not Recommended)
2. Numpad (Recommended)
3. Vi keys

### Wait Action
1. Period
2. Keypad 5
3. Clear(Untested)

### Other:
View History: V <br>
Pick Up Item: G <br>
Open Inventory: I <br>
Open Drop Inventory: D <br>

Select Item in Inventory: A-Z (Marked next to the item)

Quit Game: Escape
